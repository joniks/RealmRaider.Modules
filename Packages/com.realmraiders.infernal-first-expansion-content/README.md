# Infernal First Expansion Content

Immutable, no-engine facts for exactly one first authored expansion socket per
accepted Infernal layout. Local X/Z is right/forward in the normalized
source-node-to-socket basis. Core alone owns entitlement, persistence, geometry,
spawning, colliders, AI, combat, trap activation, rewards, UI and lifecycle.

Recipes only describe existing content IDs, bounded local placements, an optional
bypassable/non-blocking hazard fact and a cue. They create no runtime objects.
