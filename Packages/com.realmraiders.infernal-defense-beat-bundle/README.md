# Infernal Defense Beat Bundle

Read-only composition of one caller-chosen, currently eligible MGC15 beat with
its exact MGC19 eligibility evidence, MGC20 timing fact and MGC21 readability
fact. Successful bundles preserve all three immutable source object references.

The package never chooses or advances a beat and owns no clock, state mutation,
event interpretation, AI, combat, HUD, persistence, Unity integration or
automatic application. Core remains the only runtime authority.
