# Infernal Layout Materialization

This package gives Core exact cached presentation facts for every factual role in
Ashen Spur, Cinder Fork, and Ember Circuit. A mapping names its closed role kind,
floor treatment, boundary silhouette, landmark presentation role (or explicit
`none`), footprint radius, and incident graph edge IDs from which Core reads the
authored route widths.

It contains no coordinates, scene objects, generated geometry, render assets,
colliders, combat, traps, AI, saving, RNG, multiplayer, growth, or pacing
authority. Core remains responsible for materializing and rendering these facts.
