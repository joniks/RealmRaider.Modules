# Infernal Defense Pressure Timing

Immutable timing facts for the exact cached MGC15 Entry, Hound, Flame, Brute and
Heart beats in Ashen Spur, Cinder Fork and Ember Circuit. The three authored
profiles target short mobile defense arcs while retaining distinct pressure
shapes and an explicit human-readable Flame-to-Brute opportunity.

This package never measures time or applies its facts. It owns no clocks,
coroutines, AI, controllers, possession, combat, scenes, persistence, HUD or
automatic progression. Core remains responsible for interpreting a resolved,
validated profile and for every runtime decision.
