# Infernal Invader Traversal

No-engine authored traversal evidence for the three cached starter Infernal
defense layouts. Each recipe references the exact existing layout and pacing ID,
lists every route node and edge in traversal order, mirrors each layout edge's
safe/risk fact, and locates the Lava Gate halfway along the route edge entering
the Infernal Brute.

The package performs no runtime pathfinding and owns no scene materialization,
movement, AI, combat, trap, possession, camera, UI, persistence, reward, account,
network or multiplayer behavior. Core must resolve an exact recipe and remains
responsible for all runtime authority.
