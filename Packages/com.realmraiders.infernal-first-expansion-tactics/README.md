# Infernal First Expansion Tactics

Immutable, no-engine tactical intent for the three MGC31 Infernal first-expansion
sites. The catalogue binds each authored first socket to its exact content site,
ordered hostile content, response role and delay, trigger, cue, optional radius,
preferred existing ability and optional Flame Trap dependency.

The package validates caller-supplied snapshots and fails closed with specific
issue evidence. It does not observe gameplay or own clocks, distance checks, AI,
abilities, targeting, movement, traps, combat, possession, saves or scene output;
those remain Core responsibilities.
