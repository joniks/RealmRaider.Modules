# Starter Realm Identity Planning

A no-engine composition boundary for an explicit canonical realm ID and caller-
supplied signed seed. Sylvan and Infernal entry points delegate layout selection
to the accepted seeded starter adapter, create a validated portable identity
record, and return exact canonical UTF-8 bytes alongside the original cached
family recipe reference.

The explicit composition APIs revalidate selection evidence, catalogue order,
record fields and canonical bytes. They fail closed on cross-realm, catalogue,
selection, record or byte mismatches.

This package does not store records, generate seeds, migrate data, apply a plan
to Core or Unity, or own account, multiplayer, geometry or gameplay state.
