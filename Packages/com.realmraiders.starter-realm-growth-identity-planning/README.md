# Starter Realm Growth Identity Planning

No-engine composition boundary for an already successful MGC26 identity plan and
caller-supplied MGC18 expansion evidence. The caller supplies the growth tier and
the validated expansion result; this package re-evaluates the exact cached layout,
then accepts only the same layout, tier, capacity and authored socket order.

MGC18 results carry immutable exact source graph and tier references. Sylvan uses
the adapter's cached graph token for its exact cached recipe; Infernal uses its
cached graph directly. Equal-field copies are rejected rather than treated as
authoritative source evidence.

`ComposePersistedExact` accepts a caller-validated MGC25 identity result, its
canonical bytes, an exact cached layout and exact tier/expansion evidence. It bypasses
seeded reselection only for that supplied persisted evidence; it does not recover,
reroll, store or choose an identity.

The output snapshots canonical identity bytes and ordered socket references. It does
not resolve a player level, generate a seed, store data, materialize geometry, place
buildings, track occupancy, or own multiplayer/cloud authority.

`RealmExpansionPlan` and `RealmExpansionPlanResult` constructors are internal, so
forged successful swapped-socket results are unreachable through the public API.
Unity discovery must include the directly composed MGC18 and MGC23–MGC27 Editor
suites; MGC18 covers the public result-construction path.
