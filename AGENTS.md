# Realm Raider Modules — Agent Rules

Read the main project's `Docs/TEAM_WORKFLOW.md` when it is available. This repository is an isolated module catalogue, not a second Unity project.

- Create self-contained code and documentation only under `Packages/com.realmraiders.<feature>/`.
- Do not add Unity scenes, `ProjectSettings`, `Library`, build output, or copies of the main project.
- Do not edit the main RealmRaider checkout, commit, or push.
- Freeze each module diff for Reviewer / QA before Architect commits it.
